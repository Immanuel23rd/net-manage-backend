## Run the API
1. Install JDK 17+ and PostgreSQL. Create a database named `net-manage`.
2. Set the credentials in `src/main/resources/application.properties`
   (default: postgres / postgres, port 5432).
3. Run `./mvnw spring-boot:run` (Windows: `mvnw.cmd spring-boot:run`).
4. The API starts on http://localhost:8081.
5. Import `net-manage-midterm.postman_collection.json` and run the Seed data requests first.
